# API Reference (supplement)

Full interactive documentation is generated by FastAPI at `/docs` (Swagger
UI) and `/openapi.json`. This file summarizes the contract; the OpenAPI
schema is authoritative.

## Authentication

Every endpoint except `/health` and `/ready` requires:

```
Authorization: Bearer <service JWT>
X-Session-Id: <session id>          # optional if the token's session_id claim is sufficient
```

See `docs/security.md` for the token contract.

## `POST /api/v1/chat`

Request:
```json
{ "session_id": "uuid-or-string", "message": "How much did I spend this month?" }
```

Response:
```json
{
  "session_id": "uuid-or-string",
  "message": { "role": "assistant", "content": "You spent $2,430 this month..." },
  "metadata": {
    "intent": "SPENDING_ANALYSIS",
    "tools_used": ["get_expenses", "calculate_total_spending"],
    "data_used": true,
    "calculation_used": true,
    "needs_clarification": false,
    "period_start": "2026-08-01",
    "period_end": "2026-08-22",
    "period_phrase": "this month"
  }
}
```

No internal prompts, tool call arguments beyond `tools_used` names,
credentials, or raw database contents are ever included in the response.

## `POST /api/v1/conversations`

Creates an empty conversation for the authenticated user's session. `201`
on success, `409` if a conversation already exists for that
`(user_id, session_id)` pair.

## `GET /api/v1/conversations/{session_id}`

Returns message history + rolling summary (if any) for the authenticated
user's own session. `404` if no conversation exists for that user —
including when another user has a conversation under the same
`session_id` string (see `docs/security.md`).

## `DELETE /api/v1/conversations/{session_id}`

Deletes the authenticated user's conversation history and summary. `204`
on success (idempotent — no error if nothing existed).

## `GET /health`, `GET /ready`

Liveness / readiness checks. No authentication required. `/ready` reports
configuration checks only — it does not make live calls to OpenAI or the
backend.

## Errors

Every error follows:
```json
{ "code": "stable_machine_readable_code", "message": "Safe human-readable message.", "request_id": "..." }
```

See `app/core/exceptions.py` for the full list of `code` values and their
associated HTTP status codes.
